## What AI covers

SendyKit can expose AI-assisted workflows for:

- subject line generation
- email drafting
- rewrite-for-email transformations
- campaign insight generation

## Configuration model

AI behavior depends on the provider you configure in SendyKit. Keep provider credentials and model selection in your environment or deployment configuration.

## Usage paths

You can access AI capabilities through:

- the admin/operator UI where surfaced
- the generated API reference and REST endpoints
- automation flows that call the API directly
